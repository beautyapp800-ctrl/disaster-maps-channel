# disaster-maps-channel

English YouTube channel (no voice): every U.S. natural disaster mapped from real public data
(NOAA SPC, NOAA NHC HURDAT2, NOAA NCEI, USGS ComCat, NIFC/MTBS, NASA/NOAA imagery).
Engine adapted from the America Over Time map renderer (numpy + Pillow) plus CPU OpenGL for 3D relief.

Stage: step 1 (channel brief). Automation is OFF until the owner approves.
